# RecruitBot Web

Frontend scaffold for the Resume RAG Search project.

## Phase 1

- Vite + React + TypeScript scaffold
- Tailwind CSS setup
- Initial folder structure for ingestion, search, analytics, and shared UI
- Placeholder landing page to verify the app boots correctly

## Getting Started

1. `cd recruitbot-web`
2. `npm install`
3. `npm run dev`

## Notes

- API base URL is configured via `VITE_API_BASE_URL`
- The project structure is ready for feature-level implementation in later phases
